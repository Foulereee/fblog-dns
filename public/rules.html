1. 总则与适用范围

  • 本规则适用于本平台提供的全部服务，包括但不限于二级子域名申请与解析、DNS 记录配置、反向代理转发、DDNS 动态解析、账号体系及相关管理功能。
  • 本平台面向个人学习、技术研究与家庭服务器自用等非商业场景提供免费服务。
  • 用户在使用本平台服务时，应同时遵守中华人民共和国法律法规、用户所在地法律，以及域名注册管理机构、域名注册服务机构与上游基础设施提供商（如 Cloudflare）的相关政策。
  • 用户违反本规则的，本平台有权依据本规则及《用户协议与免责声明》采取相应处置措施。

2. 服务说明

2.1 服务内容

  • 本平台向用户分配形如 xxx.fblog.cyou 的二级子域名，并提供解析记录的配置能力；
  • 本平台另提供可选的反向代理功能，将用户子域名的访问请求透明转发至用户自行部署在受支持平台上的服务。

2.2 服务性质

  • 本服务为免费、非商业、按「现状」提供，不构成任何服务水平协议（SLA）承诺；
  • 本平台不提供任何形式的可用性、连续性、安全性或准确性保证；
  • 本平台有权基于运营需要、成本控制或合规要求，随时调整服务范围、技术实现或功能配置。

2.3 用户须自行准备的条件

  • 使用 DNS 记录方式接入时，用户须自备可对外提供服务的服务器、公网地址及 HTTPS 证书；
  • 使用反向代理方式接入时，用户须自行在其所选平台完成应用部署与维护，本平台仅承担转发职责。

3. 账号管理

3.1 注册

  • 用户须使用真实有效的电子邮箱完成注册，并通过邮箱验证码校验；
  • 每位用户应仅注册必要数量的账号，不得批量注册或使用自动化手段注册；
  • 用户注册时提交的信息应真实、准确；因信息不实导致无法接收通知或无法找回账号的，由用户自行承担后果。

3.2 账号安全

  • 账号及密码由用户自行保管，用户应对其账号下发生的一切行为负责；
  • 用户不得出借、出租、转让或共享账号；
  • DDNS 更新令牌与登录凭据具有同等效力，用户应妥善保管；一旦发现泄露，应立即在平台内重新生成；
  • 因用户保管不善导致账号或令牌被他人使用而产生的后果，由用户自行承担。

3.3 账号注销

  • 用户可联系管理员申请注销账号；
  • 账号注销后，其名下全部子域名与解析记录将被释放，且无法恢复；
  • 被平台封禁的账号，在封禁期间不予办理注销以外的其他业务。

4. 卡槽配额规则

  • 每个二级子域名占用一个「卡槽」。卡槽是占用额度，与域名是否已配置解析无关；
  • 新注册账号默认拥有 2 个卡槽；
  • 完成项目 GitHub 星标并经管理员确认后，可再解锁 3 个，合计 5 个；
  • 确有额外需求的，可联系管理员申请开通更多卡槽，由管理员视实际用途核定；
  • 本平台有权对长期未配置解析、长期无访问流量的卡槽进行回收，以释放有限的前缀资源；
  • 用户不得通过注册多个账号等方式规避卡槽配额限制。

5. 域名有效期与续期

  • 每个二级子域名的有效期为自申请之日起 1 年；
  • 有效期剩余 ≤ 6 个月时，用户可在「我的子域名」中执行续期，每次延长 1 年，续期不收取费用；
  • 到期未续期的，系统将自动释放该子域名，前缀重新开放给其他用户申请；
  • 域名被释放后，其上配置的解析记录与反向代理设置将一并清除，且无法找回；
  • 本平台不对因未及时续期而导致的域名丢失、服务中断或由此产生的任何损失承担责任。
建议在到期日前至少一个月设置日历提醒。平台可能通过站内或邮件方式提醒续期，但提醒并非义务，用户不应以未收到提醒为由主张免责。

6. 解析与接入规范

6.1 DNS 记录

  • 用户可配置 A、AAAA、CNAME 三类记录，记录值须为真实、有效、可公开访问的目标；
  • 不得填写内网地址、保留地址或指向本平台自身，不得用于构造解析环路；
  • 本平台创建的记录为「仅 DNS」模式，HTTPS 证书由用户自行配置并承担相应责任。

6.2 反向代理

  • 反向代理仅支持下列平台分配的目标域名，其余目标一律拒绝：
    • Cloudflare Workers / Pages：*.workers.dev、*.pages.dev；
    • 阿里云函数计算：*.fcapp.run；
    • 腾讯云云函数：*.tencentscf.com。
  • 本平台不提供通用反向代理服务，不得用于代理任意第三方网站；
  • 同一卡槽的 DNS 记录与反向代理互斥，只能二选一；
  • 用户不得利用反向代理功能隐藏真实源站、规避访问控制、隐藏攻击来源或从事任何规避溯源的行为。

6.3 动态解析

  • DDNS 令牌仅限用户本人用于更新本人名下卡槽的记录；
  • 不得将令牌用于自动化扫描、批量更新或任何超出个人自用范围的用途。

7. 禁止行为

用户不得利用本平台提供的域名、解析或转发能力从事下列行为。下列列举为示例而非穷尽，本平台有权对未列明但性质相近的行为作出同等认定：

7.1 违法违规内容

  • 违反中华人民共和国法律法规及用户所在地法律的一切行为；
  • 搭建、传播钓鱼网站、诈骗页面、赌博平台、色情或暴力内容；
  • 传播恶意程序、木马、勒索软件、挖矿程序或任何形式的恶意代码；
  • 侵犯他人知识产权、商标权、名誉权、隐私权或其他合法权益；
  • 冒用国家机关、企事业单位、社会组织名义，或伪造其网站；

7.2 滥用平台资源

  • 发送垃圾邮件（SPAM）、批量群发信息，或将本平台域名用于邮件群发的发信域；
  • 使用本平台域名承接或转发大规模流量，导致平台资源被异常消耗；
  • 将本平台域名用于短链接跳转、流量分发、广告联盟落地页等以规避域名封禁为目的的场景；

7.3 危害基础设施

  • 对本平台、本平台所使用的上游基础设施或任何第三方发起拒绝服务攻击（DDoS/CC）、端口扫描、漏洞探测或渗透测试；
  • 试图绕过、破坏或干扰本平台的安全机制、限流机制、配额机制或访问控制；
  • 以自动化手段高频调用本平台接口，影响其他用户正常使用。

7.4 规避与虚假行为

  • 通过批量注册账号、伪造邮箱等方式规避卡槽配额或其他限制；
  • 通过虚假信息或自动化手段骗取 GitHub 星标解锁等权益；
  • 在被处置后更换账号继续从事同类违规行为；
  • 以任何方式隐瞒、伪造身份以逃避责任追究。

  • 暂停该子域名的解析或反向代理；

  • 回收该二级子域名，前缀重新开放申请；
  • 限制账号功能或封禁账号；
  • 情节严重、涉嫌违法犯罪的，向有关主管部门报告并配合调查。
