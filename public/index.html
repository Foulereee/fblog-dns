我的子域名

🚀 用子域名部署 Cloudflare Workers / Pages（函数 / 页面）

想让 xxx.fblog.cyou 直接跑你自己的函数或静态页面？按下面三步：

  1. 在你自己的 Cloudflare 账号里创建 Workers（函数）或 Pages（页面）项目；
  2. 在项目里进入 自定义域名 / Custom domains → 添加 xxx.fblog.cyou，Cloudflare 会给你一个 CNAME 目标（形如 xxx.fblog.cyou.cdn.cloudflare.net）；
  3. 回到这里，把该目标填进下方该子域名的 CNAME 记录值即可，Cloudflare 会自动为它签发 HTTPS 证书。
这是 Cloudflare 的跨账号自定义域名（CNAME setup），免费、无需迁移 fblog.cyou 的 NS。
