如何使用

从注册账号到把 xxx.fblog.cyou 真正跑起来 —— 包含 A / AAAA / CNAME 记录怎么填，以及 Cloudflare、阿里云、腾讯云三家边缘节点的部署教程。

页面右侧（手机上是右下角）有目录，可以随时收起。

如何申请

整个申请流程只有三步：注册账号 → 占用前缀 → 设置记录。前两步占用不超过一分钟，第三步决定你的域名最终指向哪里。

1. 注册账号

  1. 打开 dns.fblog.cyou，点右上角「免费注册」；
  2. 填写用户名、邮箱、密码，勾选同意《使用规则》与《用户协议与免责声明》；
  3. 点「发送验证码」，去邮箱查收一封含 6 位验证码的邮件；
  4. 把验证码填进去，点确认，注册完成并自动登录。
没收到验证码？

先去垃圾邮件 / 广告邮件文件夹找 —— 平台用的是自建发信通道，第一次收到时很容易被邮箱判成垃圾。垃圾箱里也没有的话，等 1–2 分钟后点「重发验证码」。验证码 10 分钟内有效，过期重新发即可。

2. 申请占用子域名

  1. 登录后进入左侧「申请子域名」；
  2. 在输入框填你想要的前缀，比如 myblog；系统会实时检测是否可用；
  3. 看到绿色提示后点「申请占用」，你就拥有了 myblog.fblog.cyou。

前缀命名规则

  • 只能用小写字母 a-z、数字 0-9 和连字符 -；
  • 不能以连字符开头或结尾；
  • 长度 1–63 个字符；
  • 平台自用与常见系统名（如 www、api、mail、dns、admin 等）属于保留字，不允许占用。
申请只是「占位」

这一步只锁定前缀，此时域名还不会解析。要让它真正能用，必须继续做下面「如何使用」里的任意一种配置（DNS 记录或平台反代）。

3. 卡槽与配额

每个子域名占用一个「卡槽」。规则如下：

阶段可用卡槽怎么拿到
新账号2 个注册即有，无需任何条件
完成 GitHub 星标5 个给项目点星后由管理员标记解锁
更多按需开通联系管理员申请

每个二级域名的有效期是 1 年；剩余时间 ≤ 6 个月时可以点「续期 1 年」；到期未续会自动释放，前缀重新开放给别人申请。

4. 申请环节常见问题

  • 提示前缀已被占用 —— 换一个。已被占用的前缀即使原主人从没配置过记录，也要等他释放或到期。
  • 提示这是保留字 —— 该前缀属于平台自用或常见系统名，避免和邮件、DNS 等系统记录冲突，请换一个。
  • 卡槽满了 —— 到「我的子域名」确认有没有闲置的可以先释放；确实需要更多就联系管理员。
  • 申请后能改前缀吗 —— 不能。想换就先把旧的释放掉，再重新申请一个新的（注意释放后前缀会被别人抢走）。

如何使用

让子域名「能用」有两条互斥的路线，每个卡槽二选一：

路线 A：DNS 记录路线 B：平台反代
解析去向直接指向你填的地址指向 Cloudflare 边缘节点
是否经过 Cloudflare 代理否（灰云，直连）是（橙云）
HTTPS 证书你自己在服务器上配Cloudflare 自动提供
对源站的要求要有公网 IP 且开放 80/443无需自己服务器，目标是 Serverless 域名
目标限制任意 IPv4 / IPv6 / 域名只支持 4 类后缀（见下）
适合VPS、家用服务器、已有网站Workers / Pages / 函数计算 / 云函数
两条路不能同时用

同一个卡槽要么填 DNS 记录，要么开反代。已经开了反代再想填记录，平台会提示「与 DNS 记录互斥」，需要先关闭反代。

先认识三种记录类型

在「我的子域名」里给卡槽设置记录时，你会看到三种类型，它们的作用完全不同：

类型指向什么填写示例典型场景
A一个 IPv4 地址203.0.113.10有固定公网 IPv4 的 VPS / 云服务器
AAAA一个 IPv6 地址2001:db8::1有 IPv6 的服务器，或开了 IPv6 的家庭宽带
CNAME另一个域名myapp.example.com指向 CDN、边缘平台，或别人给你的域名
平台创建的记录是「仅 DNS」（灰云）

也就是说：域名会直接解析到你填的地址，不经过 Cloudflare 代理。Cloudflare 不会替你挡攻击、也不会替你签证书 —— HTTPS 需要你在自己服务器上配置。这是刻意的设计：让记录行为可预期，你自己完全掌控源站。

A 记录：指向 IPv4 地址

适用：你有一台带固定公网 IPv4 的服务器（VPS、云主机、独立服务器）。

操作步骤

  1. 确认服务器的公网 IPv4，例如在服务器上执行： 
    curl -4 ifconfig.me
  2. 确认 80 / 443 端口对外开放（云厂商还要在安全组 / 防火墙里放行）；
  3. 回到平台「我的子域名」，在该卡槽选择类型 A，值填那个 IPv4，点保存；
  4. 等待生效（平台用自动 TTL，通常几分钟内，最长不超过 10 分钟）。

HTTPS 证书要自己配

因为记录是灰云直连，https://你的域名 的证书由你的服务器提供。最省事的做法是 Let's Encrypt：

# 以 Nginx + certbot 为例
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d myblog.fblog.cyou

certbot 走 HTTP-01 校验，需要你的 80 端口能从公网访问、且域名已经解析到这台机器 —— 所以先把 A 记录配好，再去签证书。

常见坑
  • 填了内网地址（192.168.x.x、10.x.x.x）—— 外网无法访问，等于没配；
  • 服务器防火墙没放行 80/443 —— 解析正常但打不开；
  • 家庭宽带的 IPv4 是动态的 —— 重启光猫就变，请改用 DDNS。

官方文档：Cloudflare · 创建 DNS 记录阿里云 · 添加解析记录DNSPod · 解析记录文档

AAAA 记录：指向 IPv6 地址

适用：服务器只有 IPv6、或者你想让访客优先走 IPv6。

操作步骤

  1. 确认服务器的 IPv6 地址： 
    curl -6 ifconfig.me
  2. 在平台该卡槽选择类型 AAAA，值填 IPv6 地址（例如 2001:db8::1）；
  3. 服务器防火墙同样要放行 80 / 443。
IPv6 的三个现实问题
  • 不是所有访客都有 IPv6。只配 AAAA 的话，纯 IPv4 的网络会打不开 —— 建议 A 和 AAAA 各配一个（不同卡槽），或者确认你的用户群 IPv6 普及率足够高；
  • 家庭宽带的 IPv6 前缀会变。运营商通常只保证前缀在租期内稳定，重启光猫可能整段变化，这种情况更适合 DDNS；
  • 地址要写完整或正确缩写，不要带端口、不要带方括号。

官方文档：Cloudflare · DNS 文档阿里云 · 云解析 DNS

CNAME 记录：指向另一个域名

适用：目标不是 IP，而是一个域名 —— 比如 CDN 给你的加速域名、边缘平台分配的子域、或者朋友分享给你的地址。

操作步骤

  1. 拿到目标域名（例如某 CDN 控制台里显示的 xxx.cdn-provider.com）；
  2. 在平台该卡槽选择类型 CNAME，值填纯域名，不要带 https://、不要带路径或结尾的点；
  3. 保存后等待生效。

CNAME 的两个硬性限制

  • 不能和同名的其他记录共存。这是 DNS 协议规定 —— 一个名字要么是 CNAME，要么是别的记录，不能既是又是。所以一个卡槽填了 CNAME 就不能再填 A；
  • 不能用在根域名上。本平台给的是子域名（xxx.fblog.cyou），没有这个问题。
一个容易被忽略的点：CNAME 目标那边也要认你的域名

CNAME 只是把「你的域名」指向「他的域名」。目标那侧（CDN、边缘平台）必须已经把 xxx.fblog.cyou 加进它的域名列表，否则对方服务器收到请求时不知道该怎么处理，会直接报错或返回默认站点。这是 CNAME 配置里最常见的失败原因。

官方文档：Cloudflare · 创建 DNS 记录腾讯云 · DNSPod 文档

边缘节点教程 · Cloudflare

Cloudflare 的边缘网络覆盖最广、免费额度最实在，而且 Workers（函数）和 Pages（静态页面）在免费套餐下就能用。如果你只是想挂一个页面或一个小 API，这是最省事的选择。

部署步骤

  1. 到 Cloudflare 控制台注册/登录（免费账号即可）；
  2. 创建项目 —— 命令行方式（推荐，便于后续更新）： 
    npm create cloudflare@latest my-app
cd my-app
npx wrangler deploy
    也可以直接在控制台里点 Workers & Pages → Create 用网页模板创建，或者把 GitHub 仓库连到 Pages 做自动构建；
  3. 部署完成后你会拿到一个默认地址，形如：
    • Workers：my-app.你的子域.workers.dev
    • Pages：my-project.pages.dev
  4. 回到本平台接线：到「我的子域名」→ 该卡槽点「开启反代」→ 把这个默认地址填进去 → 保存；
  5. 访问 https://xxx.fblog.cyou，请求会被转发到你的 Worker / Pages。之后你在自己账号里改代码、重新部署，平台侧不需要任何改动。
为什么推荐用平台反代，而不是自定义域

Cloudflare 的 Workers 自定义域要求域名在同一个账号里，而 fblog.cyou 在平台账号下，所以你在自己账号里加不了它。平台反代正好绕开这个限制，而且 xxx.fblog.cyou 的 HTTPS 证书由平台的 Cloudflare 边缘自动签发，你什么都不用配。

官方文档：Workers 快速上手Pages 快速上手Wrangler CLI自定义域说明

边缘节点教程 · 阿里云

阿里云这边有两个方向，按你的需求选：

产品是什么和本平台怎么接
函数计算 FCServerless 计算，写个函数就有 HTTPS 地址，有免费额度平台反代（*.fcapp.run）
边缘节点服务 ENS把计算下沉到运营商边缘机房，偏企业向、按量计费看它分配的是域名还是 IP，分别用 CNAME 或 A 记录

方向一：函数计算 FC（推荐先试这个）

  1. 登录 阿里云函数计算控制台，开通服务（有免费额度）；
  2. 创建函数，选择 Web 函数（能直接处理 HTTP 请求）或内置的示例模板；
  3. 部署后为函数开启公网访问 / 配置 HTTP 触发器，拿到系统分配的访问域名，形如： 
    https://my-func.cn-hangzhou.fcapp.run
  4. 把域名里的 主机部分（my-func.cn-hangzhou.fcapp.run）填进平台该卡槽的「开启反代」；不要带 https://、不要带路径；
  5. 保存后访问 https://xxx.fblog.cyou 即可。
阿里云这边容易踩的坑
  • FC 的函数默认可能有鉴权开关。如果开了签名鉴权，平台转发过去的请求会被拒（返回 401/403），需要在控制台把它关掉或改为匿名访问；
  • 函数如果只监听特定路径（比如 /invoke），请确认平台转发的是根路径 —— 平台原样透传你访问的路径，所以你访问 https://xxx.fblog.cyou/invoke 才会命中；
  • 平台白名单只认 *.fcapp.run。阿里云 OSS、CDN 等其他域名不在白名单内，会被拒绝。

方向二：边缘节点服务 ENS

  1. 在 ENS 文档了解计费与开通方式，到控制台创建实例并部署你的服务；
  2. ENS 实例会提供访问方式（公网 IP 或分配的域名）；
  3. 如果是公网 IP → 用 A 记录指向它，并自行配置 HTTPS 证书；如果是一个域名 → 用 CNAME 记录指向它；
  4. ENS 侧的接入配置里也要把 xxx.fblog.cyou 登记进去（CNAME 场景尤其重要）。
ENS 值不值得用

ENS 偏向企业客户，计费方式与免费额度都和 FC 不同。如果你只是想要一个能跑起来的 HTTPS 地址，直接用函数计算 FC 更划算；ENS 的价值在于把计算放到离用户更近的运营商机房，适合有明确低延迟诉求的业务。

官方文档：函数计算 FC 快速入门创建 Web 函数边缘节点服务 ENS

边缘节点教程 · 腾讯云

腾讯云同样是两个方向：

产品是什么和本平台怎么接
云函数 SCFServerless 函数，可开启 Function URL 得到 HTTPS 地址平台反代（*.tencentscf.com）
EdgeOne（边缘安全加速平台 EO）基于腾讯边缘计算节点的加速 + 安全平台，含边缘函数接入它分配的加速域名 → 用 CNAME

方向一：云函数 SCF（推荐先试这个）

  1. 登录 腾讯云云函数控制台，新建函数（选「Web 函数」或自定义运行时）；
  2. 部署完成后，为该函数开启 Function URL（函数 URL 是腾讯云给函数分配的固定 HTTPS 入口）；
  3. 拿到形如下面的地址： 
    https://你的appid-你的urlid.ap-guangzhou.tencentscf.com
  4. 把主机部分填进平台该卡槽的「开启反代」，保存；
  5. 访问 https://xxx.fblog.cyou 验证。
腾讯云这边容易踩的坑
  • Function URL 要手动开启，不开的话函数没有可直接访问的 HTTPS 地址；
  • 注意区分 Function URL（*.tencentscf.com）和 API 网关（*.apigw.tencentcs.com） —— 平台白名单只收录前者。API 网关任何人都能挂，边界太宽，属于刻意排除；
  • 函数若配置了鉴权，同样会被平台转发拦下，需要放开匿名调用或改用无需鉴权的触发方式。

方向二：EdgeOne（边缘安全加速平台 EO）

  1. 参考 从零开始快速接入 EdgeOne，在控制台添加你的站点；
  2. EdgeOne 会分配一个加速域名给你，并在接入流程里要求你做 CNAME 指向；
  3. 因为 fblog.cyou 不在你的账号下，走不了自动接入。你可以在 EdgeOne 里手动添加 xxx.fblog.cyou 作为自定义域名，然后在本平台用 CNAME 记录指向 EdgeOne 给你的加速域名；
  4. 按 EdgeOne 的提示完成域名归属校验（通常会给你一条 TXT 记录让你去验证）；
  5. EdgeOne 侧配置好源站（回源到你的服务器或对象存储）后即可访问。
EdgeOne 与平台反代是两条不同的路

EdgeOne 走的是 CNAME（路线 A），它不在平台反代的白名单里 —— 平台反代只认 *.tencentscf.com。所以接 EdgeOne 请用 CNAME，并且 HTTPS 证书由 EdgeOne 侧负责签发。

三家怎么选？

你的需求建议
挂个静态页面 / 小 API，想最快跑起来Cloudflare Workers 或 Pages，免费额度友好、部署最快
已有阿里云生态（OSS、RDS 等）阿里云函数计算 FC，内网互通方便
已有腾讯云生态腾讯云云函数 SCF
需要边缘加速 + WAF 等安全能力腾讯云 EdgeOne，走 CNAME 接入
有自己服务器、要完全掌控直接配 A / AAAA 记录，自己签证书
统一记住一件事

走平台反代的（Workers / Pages / FC / SCF），你只需要「填一个域名」；走 CNAME 的（EdgeOne、各类 CDN），你还必须去对方控制台把你自己的域名登记进去，两边都要配。

验证与排错

配完之后，按这个顺序确认是否生效：

  1. 看解析： 
    nslookup myblog.fblog.cyou
# 或
dig myblog.fblog.cyou +short
    返回的应该是你填的 IP，或者反代场景下 Cloudflare 的边缘 IP；
  2. 看连通： 
    curl -I https://myblog.fblog.cyou
    期望 200 或 301/302；
  3. 看证书：浏览器地址栏是否显示锁标。DNS 记录路线下证书是你自己配的，没配就会出现证书告警。
现象多半是
域名完全解析不出来还没设置记录，或刚保存没到生效时间
解析对了但连不上服务器防火墙 / 云安全组没放行 80、443
证书告警DNS 记录路线没配证书，或证书不是给这个域名签的
反代保存被拒目标不在白名单四类后缀内，或填了 https:// / 路径
反代 502 / 1031目标服务本身没起来，或函数开了鉴权
偶尔打得开、偶尔打不开目标 IP 是动态的（家庭宽带）—— 用 DDNS

DDNS 动态解析（家庭宽带）

家庭宽带的公网 IP 会变，每次变了都要手动改记录太麻烦。平台的 DDNS 接口让你用一个固定 URL 自动更新：

  1. 进入「DDNS 管理」，复制属于你的更新地址（含令牌，请勿泄露）；
  2. 把这条 URL 交给路由器、NAS 或定时脚本，定期访问一次即可。
# 指定 IP 更新
curl "https://dns.fblog.cyou/api/ddns?token=你的令牌&ip=1.2.3.4"

# 省略 ip 参数：自动使用请求来源的公网 IP
curl "https://dns.fblog.cyou/api/ddns?token=你的令牌"
  • 省略 ip 时会用你当前的公网出口 IP，多数路由器场景用这种就够了；
  • 兼容 ddclient 等常见 DDNS 客户端；
  • 令牌泄露等于把该卡槽的记录更新权限给了别人，怀疑泄露时到「DDNS 管理」重新生成。

续期与到期

  • 每个二级域名有效期 1 年；
  • 剩余时间 ≤ 6 个月时，「我的子域名」里会出现「续期 1 年」按钮；
  • 到期未续期会自动释放，前缀重新开放申请，释放后无法找回；
  • 建议在手机日历上给到期日前一个月设个提醒。

另外，记录与反代配置都会保留在卡槽上 —— 续期只延长有效期，不需要重新配置。

还是不行？

  • 先对照上面「验证与排错」的表格自查，多数问题能直接定位；
  • 涉及账号、卡槽、被误判滥用的问题，请联系管理员；
  • 使用前请务必读一遍 使用规则 与 用户协议与免责声明 —— 违规域名会被回收，且可能导致整个 fblog.cyou 受影响。
