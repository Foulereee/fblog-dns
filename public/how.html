如何使用

三步即可拥有一个免费的 xxx.fblog.cyou 二级域名。

第一步：注册账号

  1. 打开 dns.fblog.cyou，点击右上角「免费注册」；
  2. 填写用户名、邮箱、密码，勾选同意《使用规则》与《用户协议与免责声明》；
  3. 点击「发送验证码」，去邮箱查收 6 位验证码并输入，完成注册。

第二步：申请占用子域名

  1. 登录后进入「申请子域名」；
  2. 输入想要的前缀（如 myblog），系统会实时检测是否可用；
  3. 点击「申请占用」，即可占有 myblog.fblog.cyou。
申请仅占用前缀，此时还不设置记录。每个账号默认 2 个卡槽，完成 GitHub 星标可再解锁 3 个（合计 5 个）；需要更多请联系管理员。

第三步：设置 DNS 记录

在「我的子域名」中找到刚申请的域名，选择记录类型并填写目标地址：

  • A：指向 IPv4 地址，例如 1.2.3.4；
  • AAAA：指向 IPv6 地址，例如 2001:db8::1；
  • CNAME：指向另一个域名，例如 example.com。

部署 Cloudflare Workers / Pages（函数 / 页面）

想把 xxx.fblog.cyou 直接挂到你自己的 Cloudflare Workers（函数）或 Pages（静态页面）上？推荐用平台反代，免费账号也能用，而且代码和部署都留在你自己账号里：

  1. 在你自己的 Cloudflare 账号部署 Workers 或 Pages，拿到部署地址（形如 my-worker.my-name.workers.dev 或 my-project.pages.dev）；
  2. 回到本平台「我的子域名」，在对应卡槽点 开启反代，把该地址填进去并保存；
  3. 访问 https://xxx.fblog.cyou 就会转发到你的部署，之后你在自己账号里改代码、重新部署即可，平台无需任何改动。
反代只支持这几类目标：*.workers.dev、*.pages.dev（Cloudflare）、*.fcapp.run（阿里云函数计算）、*.tencentscf.com（腾讯云云函数）。不支持任意网址，比如填 https://baidu.com 会被拒绝 —— 否则平台就成了任人使用的公开反向代理。它与上面的 DNS 记录互斥——同一个子域名要么填 DNS 记录，要么开反代，二选一。

关于「把子域名加进自己的 Cloudflare」

你可能会想在自己账号里把 xxx.fblog.cyou 添加为一个站点，从而获得完整的 Cloudflare 能力。这条路目前走不通，不是平台限制，而是 Cloudflare 的产品规则：

  • 「添加站点」填子域名会被拒绝：Please ensure you are providing the root domain and not any subdomains；
  • 官方给子域名的正规通路是 CNAME setup，但它要求 Business 及以上套餐，免费账号会被拒；
  • Cloudflare for SaaS（自定义主机名）需要联系销售开通配额，不对免费账号开放。

所以别在这上面浪费时间了，直接用上面的平台反代即可达到同样的效果。

DDNS 动态解析（家庭宽带）

家庭宽带公网 IP 经常变化时，用 DDNS 自动更新。在「DDNS 管理」复制你的更新地址，配合路由器或脚本使用：

  • curl 更新：curl "https://dns.fblog.cyou/api/ddns?token=你的令牌&ip=1.2.3.4"
  • 省略 ip 参数时自动使用你当前的公网 IP；
  • 兼容 ddclient 等常见 DDNS 客户端。

续期规则

每个二级域名有效期 1 年；剩余时间 ≤ 6 个月时可点击「续期 1 年」；到期未续将自动释放，前缀重新开放申请。
