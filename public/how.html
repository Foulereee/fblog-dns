如何使用

三步即可拥有一个免费的 xxx.fblog.cyou 二级域名。

第一步：注册账号

  1. 打开 dns.fblog.cyou，点击右上角「免费注册」；
  2. 填写用户名、邮箱、密码，勾选同意《使用规则》与《用户协议与免责声明》；
  3. 点击「发送验证码」，去邮箱查收 6 位验证码并输入，完成注册。

第二步：申请占用子域名

  1. 登录后进入「申请子域名」；
  2. 输入想要的前缀（如 myblog），系统会实时检测是否可用；
  3. 点击「申请占用」，即可占有 myblog.fblog.cyou。
申请仅占用前缀，此时还不设置记录。每个账号默认 1 个卡槽，第 2 个需 GitHub 星标（即将开放），第 3-5 个联系管理员开启。

第三步：设置 DNS 记录

在「我的子域名」中找到刚申请的域名，选择记录类型并填写目标地址：

  • A：指向 IPv4 地址，例如 1.2.3.4；
  • AAAA：指向 IPv6 地址，例如 2001:db8::1；
  • CNAME：指向另一个域名，例如 example.com。

部署 Cloudflare Workers / Pages（函数 / 页面）

想把 xxx.fblog.cyou 直接挂到你自己的 Cloudflare Workers（函数）或 Pages（静态页面）上？这是 Cloudflare 的跨账号自定义域名（CNAME setup），免费、无需迁移 fblog.cyou 的 NS：

  1. 在你自己的 Cloudflare 账号创建 Workers 或 Pages 项目；
  2. 在项目里进入 自定义域名 / Custom domains，添加 xxx.fblog.cyou，Cloudflare 会给你一个 CNAME 目标（形如 xxx.fblog.cyou.cdn.cloudflare.net）；
  3. 回到本平台「我的子域名」，把该目标填进对应子域名的 CNAME 记录值，保存后 Cloudflare 会自动签发 HTTPS 证书，稍等片刻即可用 https://xxx.fblog.cyou 访问。
普通 CNAME 只是把域名指到目标；只有走上面的「自定义域名」流程，Cloudflare 才会为 xxx.fblog.cyou 签发专属证书并接管访问。

DDNS 动态解析（家庭宽带）

家庭宽带公网 IP 经常变化时，用 DDNS 自动更新。在「DDNS 管理」复制你的更新地址，配合路由器或脚本使用：

  • curl 更新：curl "https://dns.fblog.cyou/api/ddns?token=你的令牌&ip=1.2.3.4"
  • 省略 ip 参数时自动使用你当前的公网 IP；
  • 兼容 ddclient 等常见 DDNS 客户端。

续期规则

每个二级域名有效期 1 年；剩余时间 ≤ 6 个月时可点击「续期 1 年」；到期未续将自动释放，前缀重新开放申请。
